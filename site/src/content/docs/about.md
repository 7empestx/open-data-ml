open-data-ml trains machine learning models only on openly available, openly licensed public data, and publishes the methods and results so anyone can check them. Each dataset gets its own project. The first one is [windml](/windml/), which tests whether wind turbine faults can be predicted from public SCADA data and turns the same data into condition reports.

## Who we are

open-data-ml is run by **Beehive AI Labs LLC**, a small company. We build the open projects on this site and offer health assessments, condition monitoring and a free pilot to wind operators. See [Work with us](/work-with-us/).

The code is public at [github.com/7empestx/open-data-ml](https://github.com/7empestx/open-data-ml) under the MIT license, Copyright (c) 2026 Beehive AI Labs LLC. The data keeps its own licenses.

## Data policy

**Open licenses only.** We use data released under licenses that allow reuse, such as CC BY 4.0, or public-domain government works. We check the license on the original source before using a dataset and record it with the date we checked.

**Datasets we leave out.** We don't use data with no clear license, data under non-commercial terms, or data with copyleft terms that don't fit how we work. For example, the NASA IMS bearing data (no clear license) and the SKAB water-pump benchmark (copyleft) are excluded.

**Attribution.** Every published page, model card or result names the data source, links the record or DOI, states the license, and says what we changed, such as cleaning, resampling or labeling.

**No resale.** We don't sell, resell or relicense any dataset. Raw files stay with their original publishers. The repository holds only code and processed derivatives, and points to the source for everything else.

**Operator data.** If a wind operator shares their own data for a health check, it stays theirs. It's used only for that work and never published or added to public results without written permission.

## What this is not

This is research on public data. Nothing on this site is engineering advice or a guarantee about any turbine or site.
