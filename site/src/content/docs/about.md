open-data-ml is a project for training machine learning models only on openly available, openly licensed public data. Each dataset gets its own project. The first one is [windml](/windml/), which looks for early signs of wind turbine faults.

## Data policy

**Open licenses only.** We use data released under licenses that allow reuse, such as CC BY 4.0, or public-domain government works. We check the license on the original source before using a dataset and record it with the date we checked.

**Datasets we leave out.** We don't use data with no clear license, data under non-commercial terms, or data with copyleft terms that don't fit how we work. For example, the NASA IMS bearing data (no clear license) and the SKAB water-pump benchmark (copyleft) are excluded.

**Attribution.** Every published page, model card, or result names the data source, links the record or DOI, states the license, and says what we changed, such as cleaning, resampling, or labeling.

**No resale.** We don't sell, resell, or relicense any dataset. Raw files stay with their original publishers, and we point to the source rather than hosting copies.

**Operator data.** If a wind operator shares their own data for a health check, it stays theirs. It's used only for that work and never published or added to public results without written permission.

## What this is not

This is research on public data. Nothing on this site is engineering advice or a guarantee about any turbine or site.
